# Поиск вакансий и отклики

Сервис ищет вакансии для нескольких кандидатов. У каждого профиля свои критерии поиска, PDF, результаты и история откликов. Загруженный PDF используется при отправке отклика. Критерии поиска нужно настроить отдельно.

Доступны hh.ru, Getmatch, Хабр Карьера, Finder, hirehi, LinkedIn, публичные каналы Telegram и карьерные сайты Яндекса, VK, Т-Банка, Авито, X5, МТС, Магнита, RWB, Точки, Альфа-Банка и 2ГИС. Нужные источники выбираются в пульте.

## Запуск

Нужны Node.js 21 или новее и Google Chrome. В папке проекта выполните:

```bash
npm install
npm run ui
```

Откройте `http://127.0.0.1:4321`. Если порт занят, запустите пульт командой `PORT=4322 npm run ui` и откройте `http://127.0.0.1:4322`.

Настройте критерии и нажмите **Найти вакансии**. Для поиска без пульта выполните `npm run collect`. Новые вакансии сохраняются в `out/`.

## Профили и критерии поиска

В блоке **Кандидат** можно переключить профиль или нажать **Добавить профиль**. Укажите имя профиля и специальность. Для маркетинга есть готовые направления и источники. Для другой специальности выберите подходящий шаблон, затем проверьте настройки.

Откройте **Профиль**, внесите контакты и загрузите PDF. Затем настройте направления, ключевые слова, стоп-слова, грейд, формат работы, зарплату и источники. В блоке **Исключить компании** добавьте работодателей, которых не хотите видеть в поиске. Нажмите **Найти вакансии**. PDF сам по себе не меняет поисковые критерии.

У нового профиля порог зарплаты равен 0, пока вы его не зададите. Настройки, вакансии, счетчики откликов и PDF хранятся отдельно для каждого профиля. Плановый сбор каждые 6 часов проходит по всем профилям с заданными направлениями.

Данные профилей находятся в `data/profiles/`, а результаты поиска в `out/<id профиля>/`. Эти папки не попадают в Git.

## Отправка отклика

Кнопка **Профиль** открывает имя, почту, телефон, Telegram и PDF. Проверьте данные перед первой отправкой. Они хранятся в локальной папке `data/` и не попадают в Git.

Для нужной вакансии нажмите **Откликнуться**:

1. Нажмите **Заполнить форму**. Пульт откроет Chrome, внесет контакты и прикрепит PDF.
2. Проверьте данные в Chrome. Заполните дополнительные поля и отметьте обязательные согласия на сайте.
3. Отметьте подтверждение в пульте и нажмите **Отправить отклик**. Пульт нажмет кнопку отправки на сайте.
4. Если сайт не показал явное подтверждение, проверьте окно Chrome. Нажмите **Я отправил вручную** только после успешной отправки.

Отправка из пульта настроена для Авито, 2ГИС, VK, X5, МТС, Магнита и RWB. Формы сайтов могут измениться. Логин, капчу и дополнительные вопросы нужно пройти в Chrome. Для других источников пульт открывает вакансию. После отправки на сайте отклик можно отметить вручную. Реальный отклик при проверке проекта не отправлялся.

**Сохранить** переносит вакансию в список откликов без отправки. Счетчик рядом с компанией показывает только подтвержденные отклики.

## Gmail и стадии

Проверка Gmail настраивается отдельно через Codex. В новом клоне она не включена. Если подключить Gmail и настроить задачу проверки, письма об откликах можно импортировать в основной профиль каждые 6 часов. Проверка читает письма о найме, не отправляет письма и не читает вложения. Письма hh.ru игнорируются.

В пульте откройте **Письма Gmail**. Письмо привязывается к вакансии по компании и названию. Если надежного совпадения нет, стадия существующей вакансии не меняется. Почту других профилей нужно подключать отдельно. Пароль и токен Gmail в проекте не хранятся.

## Зарплата и формат

Поле **Зарплата** задает минимальную сумму на руки. Галочка **Показывать без зарплаты** оставляет вакансии без указанной суммы. Суммы до вычета налогов оцениваются по [ставкам НДФЛ 2026 года](https://www.nalog.gov.ru/rn64/news/activities_fts/16639359/) для 12 одинаковых месячных выплат. Если налоговый статус не указан, сумма сравнивается как есть. Такие вакансии нужно проверить вручную. Диапазон остается, если его верхняя граница достигает порога. Зарплаты в другой валюте остаются для ручной проверки.

Офис и гибрид в другом городе исключаются, если город указан. Удаленные вакансии проходят независимо от города. Вакансии без города или формата остаются для ручной проверки.

## Автозапуск

На macOS можно включить сбор каждые 6 часов и постоянный запуск пульта:

```bash
npm run service install
npm run service
```

Отключить: `npm run service uninstall`. Автозапуск поиска и проверка Gmail настраиваются отдельно. Доступность отдельных карьерных сайтов зависит от сети и изменений на сайтах.
